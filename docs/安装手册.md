# 往来账管理系统 —— 安装使用手册

## 一、环境要求

| 项目 | 要求 |
| --- | --- |
| 操作系统 | Linux（Ubuntu 20.04+ / Debian 11+ 推荐）、Windows 10/11（需 Docker Desktop + WSL2）、macOS |
| 内存 | ≥ 2 GB（建议 4 GB） |
| 磁盘 | ≥ 10 GB 可用空间（数据量大时按需增加） |
| 软件 | Docker 20.10 及以上（自带 `docker compose` 插件） |

Docker 安装参考：<https://docs.docker.com/engine/install/>
Windows 请安装 Docker Desktop 并启用 WSL2 后端。

## 二、安装（约 5~10 分钟，取决于网速）

解压交付包后进入目录，执行：

```bash
./install.sh                     # 默认 80 端口
./install.sh --port 8080         # 改用 8080 端口（80 被占用时）
```

脚本会自动完成：检查 Docker → 生成 `.env`（随机 Django 密钥与数据库口令）→ 构建镜像
→ 启动 PostgreSQL / 应用 / Nginx → 等待服务就绪 → 打印访问地址。

完成后：

- 本机访问：<http://127.0.0.1/signin/>
- 局域网其他电脑：<http://服务器内网IP/signin/>（需防火墙放行对应端口）
- 初始管理员：admin / admin123（首次安装自动创建）→ 登录后立刻改密码

> 首次安装会拉镜像并编译依赖，请保持网络畅通；中途失败可直接重跑 `./install.sh`，不会丢数据。

## 三、激活授权

1. 登录后进入 **授权管理**（<http://服务器地址/license/>），页面会显示 **本机机器号**（12 位）。
2. 把机器号发给供应商，换取授权码。
   （机器号是首次运行时生成并保存在数据库里的安装标识，容器重启、升级都不变；
   只有清库或重新部署才会变。）
3. 把授权码粘贴进授权页输入框，点「激活」（仅管理员可操作）。

授权状态说明：

| 状态 | 表现 |
| --- | --- |
| 试用中（默认 30 天） | 全部功能可用，页面顶部显示剩余天数 |
| 已激活（限期/永久） | 全部功能可用，授权页显示有效期 |
| 试用结束 / 授权到期 | **只读**：可查看、查询、导出 Excel，但无法导入与保存修改 |
| 授权码无效 / 机器不匹配 | 同上，只读，请重新申请授权码 |
| 时间回拨 | 同上，只读，请把服务器时间改回正确时间 |

> 只读状态下数据不会丢失，激活后立即恢复写入。

## 四、日常使用

- 导入数据：首页 →「导入数据」（管理员）
- 导出：各列表页的「导出」按钮，导出结果为 Excel
- 改密码：登录后右上角 → 修改密码

## 五、备份与恢复

**备份**（建议每天做一次，可加入定时任务）：

```bash
docker compose exec -T db pg_dump -U ledger ledger > backup-$(date +%F).sql
```

**恢复**（会覆盖现有数据，请先备份当前库）：

```bash
docker compose exec -T db psql -U ledger -d ledger < backup-2026-10-29.sql
```

**整机迁移**：把整个安装目录连同 docker 卷一起迁移，最稳妥的做法是先在原机备份 SQL，
再到新机安装后恢复。

## 六、升级

1. 备份数据库（见上）。
2. 停止并更新代码/镜像：

```bash
docker compose down
# 把新版代码覆盖到本目录
./install.sh
```

安装脚本会自动执行数据库迁移，旧数据保留（数据卷 pgdata 不会被删除）。

## 七、卸载

```bash
docker compose exec -T db pg_dump -U ledger ledger > backup-final.sql   # 先备份！
docker compose down -v        # -v 会删除数据卷，切勿遗漏上面的备份
```

## 八、常见问题

**Q：访问页面提示 502 / 打不开？**
`docker compose logs --tail 50 web` 看错误；多数是数据库还没就绪，等 1 分钟再试或 `docker compose restart`。

**Q：80 端口被占用？**
改端口重装：`./install.sh --port 8080`。

**Q：换了服务器 / 重装系统后授权码失效？**
授权码绑定机器号。清库重新部署或换新服务器后机器号会变，把新机器号发给供应商重新签发即可
（购买时可申请不绑定机器的授权码，这种码换机、重装都能继续用）。

**Q：提示「系统时间被回拨」？**
服务器时钟被改到过去。把系统时间改回正确时间（建议开启 NTP 自动校时）后刷新页面。

**Q：想启用 HTTPS？**
把证书放到 ./certs，在 docker-compose.yml 里取消 443 端口与 certs 挂载的注释，
再把 .env 里 DJANGO_SECURE_SSL_REDIRECT 改成 True，然后 docker compose up -d。
注意：未配证书时该项必须为 False，否则 http 访问会被 301 到 https 而打不开。

**Q：忘记管理员密码？**
在安装目录执行：

```bash
docker compose exec web python manage.py changepassword admin
```

**Q：数据存在哪里？能直接拷文件吗？**
在 docker 卷 `pgdata` 中，不建议直接拷贝文件；请用 `pg_dump` / `psql` 导入导出。

## 九、目录说明

```
install.sh                 一键安装脚本
docker-compose.yml         服务编排（PostgreSQL + 应用 + Nginx）
Dockerfile                 应用镜像
deploy/nginx/docker.conf   Nginx 配置（端口、反向代理、HTTPS 可在此调整）
deploy/env.docker.template 环境变量模板
.env                       安装时生成的实际配置（含密钥，请勿外传）
```
